# Slack Post

Before drafting, read the user's last Slack post of the same kind and match its
format, length, and tone.

Write plain, friendly words about the work so it is pleasant and easy for
teammates to read. Never sound meta or AI-written: skip commentary about how you
drafted or edited the message, and skip heavy headers in short replies.

If the user asked to send it, send it via the Slack connector instead of leaving
a draft. Otherwise give one clean, copy-pasteable block.
